# 投资组合尾部风险、VaR 与压力测试

> 本文用于风险管理知识检索与软件评测，不构成投资建议。重点是 VaR、Expected Shortfall 和压力场景，而不是日常波动率优化。

## 波动率不是全部风险

标准差把收益围绕均值的离散程度压缩为一个数字，通常不区分上涨和下跌，也可能低估偏度、厚尾、跳跃和流动性枯竭。卖出期权策略在多数时间波动较低，却可能暴露于少数极端损失。

风险度量必须与持有期、可变现能力、杠杆和负债要求一起解释。

## Value at Risk

VaR 表示给定持有期和置信水平下的损失分位数。例如“一日 99% VaR 为 100 万元”意味着模型估计约 1% 的交易日损失会超过 100 万元，不代表最大损失只有 100 万元，也不表示一年只会超限一次。

历史模拟、参数法和蒙特卡洛法使用不同假设。结果应注明数据窗口、衰减权重、估值方法和置信水平。

## Expected Shortfall

Expected Shortfall（ES）衡量进入 VaR 尾部后损失的条件平均值，因此提供超过阈值后严重程度的信息。ES 通常比 VaR 更关注尾部，但同样依赖样本和模型。极端样本稀少时，99% ES 估计可能非常不稳定。

VaR 与 ES 不能替代具体压力场景。

## 相关性在压力期变化

正常时期估计的相关性可能在去杠杆和流动性冲击中同时上升，传统分散化收益减弱。资产价格下跌、保证金提高、被迫卖出和市场深度下降会形成反馈循环。

只把正常协方差矩阵乘以更大的波动率，可能仍无法描述非线性和流动性效应。

## 历史与假设压力测试

历史情景复现过去危机的因子变化，具有可解释性，但未来冲击可能以不同组合发生。假设情景根据组合脆弱点设置利率、信用利差、股价、汇率、波动率和流动性折价的联合变化。

场景应保持经济一致性。例如信用利差急剧扩大时，风险资产相关性、融资成本和市场深度也可能恶化。

## 反向压力测试

反向压力测试从不可接受结果出发，例如资本跌破限额或保证金无法满足，再寻找可能导致该结果的因子组合。它帮助识别传统场景库没有覆盖的脆弱路径。

反向压力不是预测最可能发生的事件，而是检验“什么情况会让当前策略失效”。

## 流动性与持有期

VaR 常假设可以在固定持有期以模型价格平仓。大额头寸可能需要多日退出，并产生市场冲击。压力测试应按成交量、买卖价差和市场深度调整可变现价值，考虑赎回和保证金现金需求。

账面盈利不能用于支付当日保证金，现金流时间结构同样重要。

## 回测与模型治理

VaR 回测比较实际损失超过预测 VaR 的次数，但通过次数正常不代表模型覆盖所有尾部风险。数据错误、估值缺陷和组合变化都可能影响回测。模型应独立验证、记录限制，并对异常超限进行原因分析。

## 风险报告

完整报告应同时展示 VaR、ES、历史和假设压力损失、最大回撤、流动性指标、集中度和风险限额。单一指标不能作为自动投资决策依据。
