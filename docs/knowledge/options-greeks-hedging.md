# 期权希腊字母与对冲执行

> 领域：衍生品风险管理。本文聚焦希腊字母敞口的计量与再对冲执行细节，不推导定价模型，也不重复期权合约基础与组合尾部风险度量，不构成投资建议。

## Delta 与方向敞口

Delta 衡量期权价值对标的价格微小变动的一阶敏感度，看涨在 0 到 1 之间，看跌在 −1 到 0 之间。把它乘以合约乘数与持仓数量，可折算为等价标的数量，该折算值才是交易台真正管理的方向敞口。

Delta 中性指组合净敞口接近零，使小幅价格波动带来的一阶损益相互抵消。中性是瞬时状态而非持久属性，标的一动、时间一过就会漂移。把 Delta 中性理解为没有风险是错误的，它只中和了一阶方向敞口。

## Gamma 与再对冲频率

Gamma 描述 Delta 随标的价格变化的速度。Gamma 越大，标的每移动一个单位，Delta 漂移越快，维持中性所需的再对冲交易越频繁，累计的买卖价差与市场冲击成本也越高，对冲本身成为持续支出。

临近到期的平值期权 Gamma 最高，Delta 可能在很短时间内从接近零跳到接近一。多头 Gamma 的组合再对冲时倾向于低买高卖，可回收部分权利金；空头 Gamma 则被迫追涨杀跌，标的波动越剧烈，再对冲亏损越大。

## Theta 与 Gamma 的对偶

Theta 衡量其他条件不变时期权价值随时间流逝的衰减速度，通常买方为负、卖方为正。做空 Gamma 即做多 Theta：卖方每天收取时间价值，代价是承担标的大幅移动时的再对冲亏损。

对偶关系决定策略的盈亏结构。已实现波动率低于建仓时的隐含波动率，收取的时间价值通常盖过再对冲成本；已实现波动率更高时，Gamma 亏损会吞掉全部时间价值收益，判断两者的差额是空头策略的核心。

## Vega 与波动率敞口

Vega 衡量隐含波动率变动一个百分点时的期权价值变化，买入期权无论看涨看跌都是正 Vega。它在平值附近最大，并随剩余期限延长而上升，因此长期合约是波动率水平的主要载体。

方向中性的组合仍可能有巨大的 Vega 敞口。用近月合约对冲远月敞口会留下期限结构错配：整条波动率曲面平移与前端单独抬升，对同一组合的影响完全不同，需要按期限桶分别计量。

## 隐含波动率与偏斜

隐含波动率是把市场价格代入定价公式反解出的波动率，它是报价的另一种表达，不是对未来波动的预测。同一标的、同一到期日下，不同行权价反解出的隐含波动率通常并不相等。

把这些点连成曲线，股票指数常呈现向低行权价倾斜的偏斜，外汇则更接近两端翘起的微笑。曲面形状意味着单一 Vega 数字不足以描述风险，还需分解出对偏斜与曲率的敏感度。

## 平价关系与 Rho

对同一标的、同一行权价、同一到期日的欧式期权，看涨与看跌价格受无套利条件约束：

```text
C − P = S − K × e^(−rT)
```

买入看涨同时卖出看跌可合成多头标的头寸，其方向敞口接近满仓持有。式中的折现项也解释了 Rho：利率上升抬高看涨价值、压低看跌价值。短期合约上 Rho 常被其他敞口淹没，长期合约与跨货币期权则必须纳入两条利率曲线。股息与借券成本会让等式偏离，偏离反映的是融资条件而非套利机会。

## 离散对冲误差与成本

连续对冲只存在于理论中。实际再对冲按固定时间间隔或 Delta 阈值触发，两次调整之间标的的移动会留下二阶残差，这就是离散对冲误差，其规模大致与 Gamma 和区间内价格变动的平方成正比。

提高频率能压低复制误差，却近似线性地推高交易成本，因此存在折中的最优带宽。常见做法是设置 Delta 容忍带，敞口越过带宽才调整；带宽应随交易成本上升而放宽，随 Gamma 上升而收窄。

## 卖方尾部风险与保证金

卖出期权的损益高度不对称：收益上限就是收到的权利金，损失在标的极端移动时可能远超权利金，裸卖看涨在理论上没有上界。平稳的日常收益容易掩盖这种不对称。

波动率跳升会同时抬高保证金要求与估值亏损，触发保证金追缴，而追缴必须用现金满足，账面浮盈无法抵扣。本文只覆盖敞口计量与对冲执行，组合层面的尾部风险度量与外汇敞口的工具选择应查阅相应主题文档。
