# 相对估值：可比公司、可比交易与倍数口径

> 领域：企业估值。本文聚焦倍数法的选择、口径一致与可比样本构建，与现金流折现及终值敏感性主题回答的是不同问题，不构成投资建议。

## 相对估值回答的问题

相对估值不推导内在价值，而是回答"市场当前为同类资产的每单位盈利、现金流或收入支付多少钱"。绝对估值则从企业自身现金流出发，通过折现回答"按给定假设这家企业值多少"。

两条路径结论不一致时不必强行调和，差异本身就是信息，往往来自市场预期与模型假设的分歧。本文只讨论横向对标这一侧，现金流预测与终值计算属于折现估值主题。

## 可比公司法与可比交易法

可比公司法取二级市场上业务相近公司的价格计算倍数，反映少数股权的持续经营定价。可比交易法取历史并购案例的成交对价，其中隐含控制权溢价与协同预期，通常高于同期二级市场倍数。

两者不能混用于同一结论：用并购成交倍数给一家不存在收购预期的公司定价会系统性偏高。该方法还受时点影响，跨越信用环境变化的案例可比性有限，引用时应披露交易日期。

## P/E 的适用与失效

P/E 把股价与每股盈利联系起来，前提是盈利为正、可持续且会计口径可比。企业亏损时 P/E 失去意义；周期底部盈利被压缩，P/E 反而显得很高，周期顶部盈利膨胀时 P/E 显得很低，这种反向读数是周期行业最常见的误读来源。

一次性损益、资产减值和税率差异都会扭曲分母，因此常改用剔除非经常项目的口径。使用预测 EPS 时应说明预测来源与对应年度，不同年度口径不应混排在同一张对比表里。

## EV/EBITDA 与资本结构中性

EV/EBITDA 的分子是企业价值，分母是支付利息与所得税之前的经营利润，因此它对杠杆水平和税率差异相对不敏感，便于比较资本结构不同的同业公司。

代价是 EBITDA 忽略资本开支与营运资本占用，重资产或高再投资企业用它会显得过于便宜。租赁准则差异会同时改变 EBITDA 与债务口径，跨地区比较前需要统一处理。它衡量经营层面的定价，而非股东最终能拿到多少现金。

## EV/Sales 与未盈利成长期

企业尚未盈利、利润率仍在剧烈变化时，盈利类倍数失去参照价值，收入类倍数成为少数可用的横向指标。EV/Sales 的隐含假设是行业最终收敛到某个稳态利润率，它其实是把利润率判断藏进了倍数里。

使用时应同时披露毛利率与收入结构，区分一次性交付收入与可续约的经常性收入。收入口径本身也需核对，代理业务下的总额法与净额法会让同样的经营规模呈现完全不同的收入数字。

## PEG 与 P/B 的边界

PEG 用 P/E 除以盈利增速，试图说明高倍数是否被增长支撑。它的脆弱之处在于增速取几年、用历史还是预测、是否为复合口径都没有统一约定，换一个假设结论就会翻转，因此 PEG 更适合初筛而非结论。

P/B 把股价与净资产比较，在银行、保险与部分重资产行业更有意义，因为账面资产较接近可交易价值，且与 ROE 直接相关。轻资产企业的核心资源不在资产负债表上，P/B 解释力很弱。

## 分子分母口径一致

倍数的分子与分母必须属于同一层级：股权口径对股权口径，企业口径对企业口径。

```text
EV = 股权市值 + 有息债务 + 少数股东权益 − 现金及等价物
股权口径：P/E、P/B、P/FCFE
企业口径：EV/EBITDA、EV/EBIT、EV/Sales
```

把企业价值除以净利润是错误搭配，因为分子包含债权人的求偿权，分母却是扣除利息后只归属股东的部分。同理，用股权市值除以 EBITDA 也不成立。口径混用的偏差方向随杠杆变化，无法用统一系数修正。

## 可比样本与中位数

可比样本的筛选标准应当写清楚：业务结构与收入构成、规模区间、增长阶段、盈利能力与所在地区市场，缺任何一项都会让"可比"退化为随意挑选。样本过窄失去统计意义，过宽则把不同商业模式混在一起。

汇总时中位数优于算术平均数，因为个别极端倍数会显著拉动均值，而这些异常值往往来自盈利接近零的公司。倍数只反映市场当下的定价共识，并非内在价值。
