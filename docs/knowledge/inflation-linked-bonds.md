# 通胀挂钩债券与实际收益率

> 领域：固定收益。本文聚焦本金指数化机制、实际收益率与盈亏平衡通胀率，与利率敏感度、曲线形状和信用利差三类文档形成区分，不构成投资建议。

## 本金指数化机制

通胀挂钩债券把本金按参考物价指数逐日调整，票面利率固定不变，但票息金额等于固定票息率乘以调整后的本金，因此票息随物价水平同步增长。到期偿还的也是指数化之后的本金。

结算时使用的指数比率等于结算日参考指数除以发行时的基准指数。这个比率同时进入应计利息和结算价，所以报价通常是"洁净实际价格"，实际交割金额还要再乘一次指数比率。

## 实际收益率的含义

通胀挂钩债券按实际收益率（real yield）报价，衡量扣除通胀后的购买力回报；普通国债报价的是名义收益率，其中已经包含对未来通胀的补偿。两条曲线口径不同，不能直接横向比较高低。

实际收益率为负并不等于持有一定亏钱，它说明市场愿意为确定的购买力保护付出成本。判断相对价值必须落在实际收益率与名义收益率的差额上，而不是任何一条曲线的绝对水平。

## 费雪关系

名义收益率、实际收益率与通胀预期之间是乘积关系：

```text
(1 + 名义) = (1 + 实际) × (1 + 通胀预期)
名义 ≈ 实际 + 通胀预期
```

第二行是常用的加法近似。通胀较低时交叉项很小，近似误差可以忽略；通胀达到两位数时，交叉项会让近似式明显低估名义收益率，此时应回到乘积形式计算。

三个变量中只有名义与实际收益率可直接观测，通胀预期是推导出的残差项。费雪关系因此更适合当作口径校验工具，而不是预测通胀的模型。

## 盈亏平衡通胀率

盈亏平衡通胀率是两类债券报价之差：

```text
breakeven = 同期限名义收益率 − 同期限实际收益率
```

它的教育意义是给出一个持平点：若持有期内的平均实现通胀恰好等于 breakeven，两类债券的名义回报大致相当。把 breakeven 直接读成"市场对通胀的预测值"是不准确的，它是两个品种的相对定价结果。

计算时两只债券应尽量匹配剩余期限、发行人和计息惯例，期限错配会让差额混入曲线形状因素。

## 通胀风险溢价

breakeven 至少包含三块：真实通胀预期、通胀风险溢价，以及指数债相对普通国债的流动性溢价差。投资者承担了通胀路径的不确定性，会要求额外补偿，这部分风险溢价通常为正。

结果是 breakeven 一般高于调查问卷或模型给出的通胀预期中值。流动性溢价方向相反，会压低 breakeven。用 breakeven 直接替代预期值，会把风险补偿误读为预期本身。拆分这三块依赖模型假设，不同方法给出的溢价估计差异不小。

## 实际久期与名义久期

实际久期度量价格对实际收益率变动的敏感度，名义久期度量对名义收益率的敏感度，两者的冲击对象不是同一个变量。风险系统若把它们汇总到同一栏，会把通胀预期变化和实际利率变化混在一起。

同期限的指数债票面利率通常低于普通国债，现金流回收更靠后，因此实际久期往往略长。组合层面可以用实际久期和 breakeven 敏感度两个维度分别刻画暴露。

## 指数滞后与通缩下限

指数滞后（indexation lag）通常为两到三个月，因为物价指数发布本身有时滞。这意味着最近期的通胀不会立刻体现在结算金额中，临近到期的品种实际上只剩下不完整的通胀保护，并会带入指数的季节性波动。

多数品种设有通缩保护下限（deflation floor）：即便累计物价低于发行时水平，到期偿还金额也不低于初始面值。这个下限只保护本金，期间票息仍按下调后的本金计算。

## 税收、流动性与边界

税收上的麻烦在于本金指数化增值往往在当期被视为应税所得，但对应现金要到到期才真正收到，形成虚增本金先纳税的现金流错配。应税账户需要提前安排缴税资金。

指数债存量与换手率通常低于普通国债，买卖价差更宽，压力期实际收益率可能因流动性而异常跳升。本文不讨论久期与凸性的计算过程、曲线节点错配，也不涉及信用补偿与尾部损失度量。
