# 外汇对冲工具与敞口匹配

> 领域：企业外汇风险管理。本文聚焦远期、掉期、NDF 与期权型结构如何匹配不同类型的外汇敞口，不讨论外汇市场结构与报价惯例，也不重复希腊字母对冲，不构成投资建议。

## 三类外汇敞口

交易性敞口来自已签约、金额与币种确定的应收应付，时点清楚，最适合用衍生工具精确覆盖。折算敞口来自把境外子公司报表折算为记账本位币，影响权益与合并报表，本身并不产生现金流。

经营性敞口最难量化，汇率长期变化会改变自身与竞争对手的相对成本和定价能力，即使公司没有任何外币合同也会受影响。用短期远期对冲经营性敞口通常无效，它需要的是产能布局与采购币种的结构性调整。

## 远期定价与远期点数

远期合约锁定未来某一日的汇率，把不确定的换汇价格变成确定值。它是义务而非权利，汇率朝有利方向变动时同样必须履约。在可自由兑换且资金可流动的货币对上，远期价格由无套利条件决定：

```text
F = S × (1 + r_quote) / (1 + r_base)
```

r_base 与 r_quote 是两种货币在对应期限的利率。市场通常报远期点数而非 F，报价货币利率更高时点数为正，称为升水。把远期价格当作市场对未来汇率的一致预期，是财资管理中最常见的误解。

## FX swap 与展期

FX swap 由一笔即期与一笔反向远期组成，只交换两个方向的本金而不改变净敞口方向，常用于把已有对冲头寸的到期日往后推。实际现金流晚于原对冲到期日时，用掉期展期通常比平仓再重做更省成本。

掉期价格就是两条腿之间的远期点数，本质上是一笔基于利差的融资交易。跨越季末与年末等资金紧张时点的掉期点数可能明显偏离平价，反映的是短期融资溢价而不是汇率预期。

## 无本金交割远期

NDF 适用于存在资本管制、离岸交割不便或本币不可自由兑换的货币。它到期不交换本金，只按约定汇率与官方定盘价的差额，用美元等可兑换货币净额结算，因此不需要在岸账户与购汇额度。

NDF 价格更多由离岸供求与管制预期决定，可能长期偏离用在岸利率算出的平价水平。即使名义金额已经覆盖，NDF 仍会留下定盘价与企业实际换汇价格之间的基差风险。

## 货币互换与长期负债

货币互换在期初与期末交换不同币种的本金，存续期内定期交换利息，期限可以覆盖数年。它天然匹配外币长期借款或跨境投资的本息现金流，把外币负债在经济实质上转换为本币负债。

与滚动短期远期相比，货币互换一次锁定整条期限的汇率与利率，避免了反复展期的价格不确定，但占用更多交易对手信用额度，且汇率大幅变动后提前终止的估值成本可能很高。

## 期权型对冲与领口

买入外汇期权保留了汇率有利变动时的收益，只放弃权利金，适合金额或发生概率不确定的敞口，例如尚未中标的投标报价。缺点是权利金构成确定的前期现金支出，需要预算科目承接。

领口结构在买入保护性期权的同时卖出一个反向期权，用收到的权利金抵扣支出，可以做到接近零成本，代价是放弃超出卖出行权价之外的有利变动。它把结果限制在区间内，而不是锁定为一个点。

## 对冲比率与展期风险

对冲比率是名义对冲金额与预期敞口的比值，很少需要设为百分之百。预测现金流本身有误差，过度对冲会在实际敞口未发生时留下反向的投机头寸。分层递减更常见：近月覆盖高，远月覆盖低。

用连续滚动的短期合约覆盖长期敞口，实际上是把汇率风险替换为展期风险：每次续做时的远期点数、信用额度与市场流动性都可能变化，长期累计的对冲成本因此并不确定。

## 对冲有效性与损益错配

对冲会计要求对冲工具与被对冲项目建立正式指定并证明有效性，否则衍生品按公允价值计入当期损益，而被对冲的预期交易尚未确认，就会出现错配：经济上敞口已覆盖，报表上却出现波动。

经济对冲有效与会计对冲有效是两回事，混淆两者是外汇管理中的高频误区。本文只讨论工具与敞口类型的匹配，市场结构与报价惯例、期权敞口的希腊字母计量，应查阅相应主题文档。
